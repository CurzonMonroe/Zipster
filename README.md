# Zipster

Open, preview, extract, edit, and create archives in a focused desktop workspace.

## Install on macOS

```sh
brew tap CurzonMonroe/zipster
brew install --cask zipster
```

Homebrew chooses the Apple Silicon or Intel build automatically. macOS Monterey (12) or later is required. To update, run `brew update` followed by `brew upgrade --cask zipster`.

You can also download the appropriate archive from [Releases](https://github.com/CurzonMonroe/Zipster/releases), verify its SHA-256 checksum, extract it, and copy `Zipster.app` to Applications.

These builds are not Developer ID signed or notarized. macOS may require approval through its normal Privacy & Security controls before the first launch.

## Support

Please use this repository’s issues for reports. Include the information from **About Zipster → Copy version info**, steps to reproduce, and the archive format. Avoid uploading confidential archives.

This repository contains public release downloads and documentation.
